# Algoritmos Fundamentais com Testes Unitários (Jest)

Este projeto reúne a implementação de seis algoritmos fundamentais em JavaScript utilizando boas práticas de **Clean Code** e **Programação Defensiva**, acompanhados das respetivas suítes de testes automatizados com **Jest**.

## Algoritmos Implementados
- **Contagem:** conta quantos números inteiros num conjunto são menores ou iguais a um limite.
- **Fibonacci:** gera a sequência de Fibonacci até `N` termos.
- **MDC:** calcula o Máximo Divisor Comum entre dois números inteiros.
- **Número Primo:** verifica se um número inteiro é primo.
- **Quicksort:** ordena uma lista numérica de forma crescente.
- **Somatório:** calcula a soma total dos elementos de um array numérico.
